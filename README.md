# Day 43 — Resume/Portfolio Website

**120 Days of Code** | NIT Rourkela | Mechanical Engineering

## What this is
A professional resume/portfolio website with a clean
design, printable resume and all sections a recruiter needs.

## How to view
Open `index.html` in your browser.
Enable GitHub Pages for a live URL.

## Features
- Hero with typewriter effect
- Education, Skills, Projects, Experience sections
- Printable resume layout
- Smooth scroll animations
- Mobile responsive
